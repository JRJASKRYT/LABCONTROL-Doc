# 💻 LABCONTROL - Sistema de Gestión de Laboratorios
*Universidad del Valle - Centro de Cómputo (Sede La Paz)*

---

## 📌 Descripción del Proyecto
Sistema para la administración, reserva y control de disponibilidad de los laboratorios de computación del Centro de Cómputo de UNIVALLE La Paz.
